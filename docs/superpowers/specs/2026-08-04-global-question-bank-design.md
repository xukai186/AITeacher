# 全局题库（混合范围）— 产品设计规格

**日期：** 2026-08-04  
**状态：** 待实现  
**依赖：** 现有自测与 `paper_gen_jobs`（`SelfTestPaper` / `SelfTestQuestion`）、大纲 `syllabus_nodes`、admin/staff RBAC、模型策略（OCR / 属性补全）

---

## 1. 背景与目标

当前自测题目仅存在于单张卷的 `self_test_questions` 中：AI 每次现出题，出完即散落在卷面快照里，**没有可复用的题目资产层**。老师/管理员端也没有录题入口。

目标：建立统一题库，使：

1. 自测**优先从题库选题**，不足时再 AI 补题；
2. AI 补出的题**自动回灌题库**（待审核后可复用）；
3. 老师/管理员可**极简录题**（只录题面），由模型自动补科目/知识点/难度等属性；
4. 支持**上传单图**识别题面后确认入库（首期一图一题）。

---

## 2. 已确认的产品决策

| 维度 | 决策 |
|------|------|
| 题库范围 | **混合**：平台公共题（`global`）+ 机构私有题（`org`）；自测先抽机构私有，再补公共 |
| 审核策略 | **按来源分级**：手工确认后的录题可直接 `active`；AI 回灌与 OCR 导入默认 `pending_review` |
| 首期题型 | 单选、多选、填空、简答（不含作文/大题） |
| 图片导入 | 首期**一图一题**；多题切分后续再做 |
| 自测组卷 | **优先题库，不够再 AI 现出并回灌** |
| 架构路径 | **方案 A**：独立题库主模型 + 组卷器接入；卷内题仅为快照 |
| 录题体验 | 录入**只需题目本身**；科目/知识点/难度等由模型自动补全，保存前人工可改确认 |

---

## 3. 数据模型与题目生命周期

### 3.1 题库主表 `question_bank_items`

题目资产的唯一权威来源。核心字段：

| 字段 | 说明 |
|------|------|
| `scope` | `global` \| `org` |
| `org_id` | `org` 题必填；`global` 为空 |
| `subject_code` | 科目 |
| `knowledge_node_id` | 可选，挂叶子知识点 |
| `q_type` | `single_choice` \| `multi_choice` \| `fill_blank` \| `short_answer` |
| `stem` | 题干 |
| `choices_json` | 客观题选项 |
| `answer_key` | 答案 / 参考答案 |
| `analysis_text` | 解析（可空；模型可草稿） |
| `difficulty` | 整数 `1`–`5`（模型建议 + 人工可改） |
| `source_type` | `admin_manual` \| `staff_manual` \| `ocr_import` \| `ai_generated` |
| `status` | `draft` \| `pending_review` \| `active` \| `disabled` \| `rejected` |
| `created_by` / `reviewed_by` / `reviewed_at` | 审计 |
| `source_image_asset_id` | OCR 原图附件（可空） |

仅 `status=active` 可被自测抽到。  
`draft` 仅用于「属性补全后、人工确认提交前」的临时态（可不落库，或短时落库后确认时转 `active` / `pending_review`）；确认页取消可丢弃。

### 3.2 卷面快照与关联

现有 `SelfTestQuestion` **保留为试卷快照**，不删改历史卷面。新增：

| 字段 | 说明 |
|------|------|
| `bank_item_id` | 可空 FK → `question_bank_items`；题库选题或 AI 回灌后写入 |
| `selection_source` | `bank_org` \| `bank_global` \| `ai_fallback` |

题库题后续被编辑、禁用时，**不影响**已生成卷面内容。

### 3.3 生命周期

```
手工录题（确认后）     → active
OCR 导入（确认后）     → pending_review → active | rejected
AI 自测补题            → pending_review（同时拷贝进当前卷快照供作答）
                       → 审核通过后进入可复用池
active 题              → disabled（下架，不再抽题）
```

## 4. 自测组卷与选题流程

学生「生成自测」仍走现有异步 `paper_gen_jobs`，但 job 执行从「纯生成」改为「先选题、再补题、再成卷」。

### 4.1 约束

- 科目、目标题量、允许题型（首期四类）、知识点范围（可结合掌握度/周目标，首期至少按科目 + 可选节点）。
- 学生侧去重：优先避开该生近期做过的 `bank_item_id`。

### 4.2 选题顺序

1. 本机构 `scope=org` 且 `active`；
2. 平台 `scope=global` 且 `active`；
3. 仍不足 → AI 按缺口描述补题。

每道 AI 补题：先写 `QuestionBankItem`（`scope=org`，`org_id`=该生所属机构，`status=pending_review`，`source_type=ai_generated`），再拷贝为当前卷 `SelfTestQuestion`（`selection_source=ai_fallback`）。本机构老师/管理员在待审核列表中审核这类题。

### 4.3 失败与可解释性

- 题库空但 AI 成功：学生无感；AI 题仅待审核后复用。
- 题库与 AI 均失败：试卷标记失败，返回明确错误，不留下空卷。
- 每道卷题记录 `selection_source`，便于排查来源与质量。

## 5. 老师 / 管理员录题与 OCR

### 5.1 权限

| 角色 | 能力 |
|------|------|
| `org_admin` | 本机构题 CRUD；平台公共题查看/审核/禁用；改归属（org ↔ global，首期可限管理员） |
| `org_staff`（老师） | 本机构题新增/编辑；待审核本机构题；**不可**直接改平台公共题 |

前端：admin / staff 各增加「题库」入口（列表、新建/确认、待审核）。

### 5.2 极简录题 + 属性自动补全

录入只要求**题目本身**：

- 客观题：题干 + 选项 + 答案；
- 简答：题干 + 参考答案。

科目、知识点、难度、解析草稿、题型校验等由模型补全。保存前进入**确认页**，展示模型建议，人工可改再提交。

链路：

`手工输入 / OCR 提取题面` → `结构化题面` → `模型补全属性` → `人工确认` → 入库

状态：

- 手工录题（确认提交）→ `active`
- OCR 导入（确认提交）→ `pending_review`

### 5.3 OCR（首期）

- 一图一题；上传后保存原图，再 OCR/视觉模型抽结构化题面，再走属性补全与确认页。
- 不做多题切分、批量导入、向量语义去重（后续扩展）。

---

## 6. 审核与去重

### 6.1 审核

待审核列表处理 `ocr_import` 与 `ai_generated`。动作：`通过` → `active`；`驳回` → `rejected`；上线后可 `禁用` → `disabled`。无复杂多级工作流。

### 6.2 去重（首期三层）

1. **精确去重**：同 scope/机构下题干 + 题型一致 → 提示重复，避免重复入库。
2. **AI 回灌去重**：补题与已有题高度一致（精确或规范化后一致）→ 复用已有 `bank_item_id`，不新建。
3. **学生侧去重**：组卷避开该生近期做过的题库题。

首期不上向量语义去重。

---

## 7. 实施分期

| 阶段 | 内容 |
|------|------|
| **P1** | 题库主模型与迁移；admin/staff CRUD；手工录题 + 属性补全确认；审核状态与待审核列表 |
| **P2** | 自测组卷器：题库优先 → AI fallback → 回灌 pending_review；`SelfTestQuestion` 关联字段 |
| **P3** | 图片上传、OCR 提取、确认入库 |

同一规格文档覆盖三期；实现计划可按 P1→P2→P3 拆任务。

---

## 8. 测试要点

- 后端：创建/状态流转；组卷机构优先再公共；不足时 AI fallback 并回灌；精确去重与学生去重。
- 前端：题库列表、确认页、待审核；OCR 导入确认（P3）。
- 集成：生成自测可抽库题；缺口补题可作答且题库出现 pending。
- 回归：现有自测提交、批改、错题本、eligibility 不被破坏。

---

## 9. 明确不在首期范围

- 多题切分 / 批量图片导入
- 作文等超纲题型
- 向量语义查重
- 学生端直接向题库贡献题目
- 跨机构私有题共享（仅 `global` 与本 `org`）

---

## 10. 成功标准

1. 老师/管理员可只录题面完成入库，属性由模型建议并经确认。
2. 自测在有足够 `active` 题时可不依赖 AI；不足时仍能成卷，且新题进入待审核。
3. OCR 一图一题可走通「识别 → 确认 → pending_review」。
4. 历史自测卷面不因题库编辑/下架而改变。
